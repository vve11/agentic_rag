## 2. 正文版本一：直接发布版

```text
最近整理了一个我自己很喜欢的 AI Agent 项目：

Paper RAG Agent，一个面向论文研读场景的 AI 工作台。

它不是那种“接一个大模型，然后做成智能客服”的项目。
更像是一个给科研/学习场景用的论文助手：

能导入论文，
能围绕论文内容提问，
能展示引用证据，
能整理成 Wiki/知识笔记，
也能作为一个完整的前后端项目来演示。

我觉得它比较适合想做 AI Agent / RAG 项目的同学，尤其是想把项目写进简历、面试时能讲清楚的人。

和普通智能客服 Agent 的区别是：

智能客服更偏业务接待、FAQ、固定流程；
这个项目更偏知识研读、论文问答、证据引用和项目答辩。

所以它不是一个“看起来能聊天”的 demo，
而是更适合讲：
我做过一个完整 AI 应用项目。

我后面会把这个项目整理成课程版：
包含完整项目、运行手册、演示路径、简历表达和常见报错排查。

如果你也想做一个能写进简历的 Agent / RAG 项目，可以蹲一下。
```

所以我做了一个不太一样的方向：

Paper RAG Agent

而是帮助用户围绕论文进行问答、整理、引用和沉淀。

## 4. 正文版本三：更克制专业版

Paper RAG Agent
一个面向学术论文研读的 Agent / RAG 项目。

我觉得它适合作为课程项目/简历项目，因为它不是只证明“我会调模型 API”，而是能展示一个 AI 应用从界面、数据、问答到演示的完整形态。
